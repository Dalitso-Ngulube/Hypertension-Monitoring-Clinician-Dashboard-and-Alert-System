# Hypertension-Monitoring-Clinician-Dashboard-and-Alert-System 


## Overview
This project is a web-based system designed to help clinicians monitor and manage hypertension. It collects patient blood pressure (BP) data, analyzes trends, classifies risk levels, and generates alerts for abnormal readings.

## Features
- Patient blood pressure data collection via API
- Interactive dashboard for data visualization
- Blood pressure trend analysis
- Risk classification based on WHO guidelines
- Real-time alerts for critical BP levels
- Secure authentication and data handling

## Tech Stack
- **Frontend:** React.js, HTML, CSS, JavaScript
- **Backend:** Django (Python)
- **Database:** PostgreSQL
- **APIs:** RESTful API
- **Visualization:** Chart.js
- **Authentication:** JWT

## System Architecture
- **Frontend:** Displays dashboard, charts, and alerts
- **Backend:** Handles logic, APIs, and data processing
- **Database:** Stores patient data and BP readings
